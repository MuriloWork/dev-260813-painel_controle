Infográficos-prompts

Prompt 1:1

Crie um infográfico educacional premium em formato quadrado 1:1 sobre \[TEMA\].

O visual deve parecer uma mistura entre:
• pôster científico futurista
• design editorial premium
• interface tecnológica moderna
• arte cinematográfica minimalista
• estética Apple / revista Wired / documentário premium

O design deve ser limpo, sofisticado e altamente visual, otimizado para Instagram, Pinterest e posts virais de redes sociais.

ESTILO VISUAL:
Ultra detalhado
Minimalismo premium
Visual tecnológico sofisticado
Composição limpa e organizada
Estética cinematográfica moderna
Aparência editorial de alto nível
Qualidade hiper realista

FUNDO:
Usar fundo escuro premium:
• preto profundo
• azul espacial escuro
• grafite tecnológico
• gradiente futurista suave

Adicionar:
• glow tecnológico discreto
• iluminação cinematográfica
• reflexos suaves
• atmosfera elegante
Evitar excesso de elementos no fundo.

ELEMENTO PRINCIPAL:

Posicionar um render 3D ultra realista de \[TEMA\] no centro da composição.
O elemento principal deve ocupar grande parte da imagem.

Requisitos:
• foco extremamente nítido
• texturas hiper detalhadas
• iluminação cinematográfica
• aparência científica realista
• profundidade profissional
• silhueta limpa e impactante

ESTRUTURA DO INFOGRÁFICO:
TÍTULO:

Adicionar um título grande e sofisticado em caixa alta:
\[TEMA\]

Usar tipografia premium moderna:
• branca
• prata
• azul tecnológico
• ciano suave

SUBTÍTULO:
Adicionar uma frase curta explicando:
• funcionamento
• curiosidade científica
• importância
• mecanismo principal

PAINÉIS INFORMATIVOS:

Adicionar apenas 2 ou 3 painéis modernos.

Os painéis devem ser:
• grandes
• elegantes
• fáceis de ler
• visualmente equilibrados

Usar:
• glassmorphism
• cartões semi transparentes
• zooms circulares
• linhas finas minimalistas
• mini diagramas sofisticados
Evitar excesso de informação.

As informações devem parecer:
• premium
• rápidas
• visualmente inteligentes

CATEGORIAS SUGERIDAS:
• curiosidades
• funcionamento
• estrutura
• mecanismo interno
• fatos científicos
• detalhes importantes

RODAPÉ:
Adicionar pequenos elementos tecnológicos discretos:
• mini gráficos
• ícones científicos
• símbolos futuristas
• estatísticas minimalistas

PALETA DE CORES:
Usar cores sofisticadas:
• azul espacial
• ciano
• branco gelo
• prata
• roxo tecnológico
• verde esmeralda discreto

Evitar:
• cores exageradas
• neon excessivo
• aparência gamer
• visual infantil

QUALIDADE:
Qualidade 8K
Render estilo Octane
Iluminação cinematográfica
Visual editorial premium
Composição perfeitamente equilibrada
Espaçamento sofisticado
Profundidade realista

NEGATIVE PROMPT:
Evitar:
layout bagunçado
texto excessivo
micro detalhes ilegíveis
muitos painéis
poluição visual
cores exageradas
visual barato
baixa qualidade
anatomia errada
objetos duplicados
tipografia ruim
elementos cortados
muitos conectores
visual confuso
marca d’água
logos

OBJETIVO FINAL:
O resultado deve parecer um pôster científico premium criado por uma grande empresa de tecnologia ou revista futurista.
A imagem deve transmitir:
• inteligência
• sofisticação
• tecnologia
• impacto visual
• curiosidade científica

Todo o texto deve estar em português do Brasil.

Prompt 9:16

Crie um infográfico educacional premium em formato vertical 9:16 sobre \[TEMA\].

O visual deve parecer um pôster científico cinematográfico moderno, criado para redes sociais como TikTok, Instagram Reels e YouTube Shorts.

Misture:
• estética editorial premium
• design futurista informativo
• realismo cinematográfico
• organização visual limpa
• aparência viral e altamente profissional

ESTILO VISUAL:
Ultra detalhado
Visual impactante
Composição minimalista e sofisticada
Estética de documentário científico moderno
Layout organizado e fácil de entender
Qualidade ultra realista

FUNDO E ILUMINAÇÃO:
Fundo neutro elegante com gradiente suave
(branco, cinza claro, bege ou tons tecnológicos sutis)
Iluminação de estúdio cinematográfica
Sombras suaves
Separação clara entre fundo e elemento principal
Aspecto premium refinado

ELEMENTO PRINCIPAL:
Posicione um render 3D ultra realista de \[TEMA\] no centro da composição.
Requisitos:
• anatomia ou estrutura altamente precisa
• texturas hiper realistas
• detalhes naturais ricos
• profundidade cinematográfica
• foco extremamente nítido
• silhueta limpa para facilitar leitura do infográfico

ESTRUTURA DO INFOGRÁFICO:

TOPO:
Título grande em caixa alta:
\[TEMA\]
Adicionar subtítulo elegante resumindo:
• funcionamento
• estrutura
• comportamento
• importância
• curiosidades científicas
• características únicas

PAINÉIS EDUCACIONAIS:

Adicionar entre 4 e 6 painéis modernos ao redor do tema principal.

Cada painel deve conter:
• indicadores numerados
• ícones minimalistas
• linhas finas de conexão
• mini diagramas científicos
• zoom circular de detalhes
• cartões com cantos arredondados
• sombras suaves
• tipografia limpa e moderna

Categorias sugeridas:
• anatomia
• sistemas internos
• funcionamento
• adaptações
• habitat
• evolução
• mecanismos de defesa
• dados científicos
• curiosidades
• estatísticas

PERSONAGEM ESPECIALISTA:
Adicionar no canto inferior um pequeno pesquisador, cientista ou educador.
Características:
• estilo semi-realista moderno
• apontando para o tema principal
• segurando tablet, holograma, lupa ou interface tecnológica

RODAPÉ INFORMATIVO:
Adicionar barra inferior elegante contendo:
• fatos rápidos
• mini comparações
• ícones científicos
• estatísticas
• mini diagramas
• pequenos elementos informativos

PALETA DE CORES:
Usar cores inspiradas naturalmente no tema.
Cores de destaque sugeridas:
• azul neon
• ciano
• verde esmeralda
• laranja energético
• roxo tecnológico
• amarelo científico
• vermelho intenso

Usar contraste de forma estratégica para direcionar atenção visual.

QUALIDADE FINAL:
Qualidade 8K
Texturas hiper detalhadas
Estilo Octane Render
Iluminação cinematográfica
Visual editorial premium
Espaçamento perfeitamente equilibrado
Tipografia sofisticada
Composição limpa e organizada

EVITAR:
imagem borrada
baixa qualidade
texto ilegível
anatomia errada
layout bagunçado
muitos elementos aleatórios
proporções ruins
poluição visual
sombras ruins
objetos duplicados
elementos cortados
marcas d’água
logos
visual amador
texto excessivo

OBJETIVO FINAL:
O resultado deve parecer uma mistura entre:
• revista científica futurista
• documentário premium
• infográfico viral cinematográfico
O infográfico deve ser extremamente impressionante visualmente, fácil de entender e otimizado para viralização em redes sociais.
Todo o texto deve estar em português do Brasil.
